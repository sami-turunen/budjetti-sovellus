## Budgetti-sovellus ##

Budgetti-sovellukseen pystytään syöttämään käyttäjän kuluja, sekä menoja.
Joiden perusteella sovellus laskee, käyttäjän menot ja tulot, sekä tekee sen perusteella kaavion.

## Käytetyt teknologiat

# Backend
- Node.js

Kirjastot:
- Express
- Tietokantana MongoDB

# Frontend
- React

Kirjastot:
- Angular
- Kaavioiden tekoon, Chart.js

## Käyttöönotto ja asennus

# Esivaatimukset

- Node.js v22.18.0
- Npm v10.9.3

## Asennusohjeet

# Cloona projekti githubista
- git clone https://github.com/sami-turunen/budjetti-sovellus.git
- Avaa kloonattu kansio Visual Studiossa

- Avaa Visual Studion komentorivi
- npm install

# Käyttö
- Mene backend kansioon
- cd backend

- Käynnistä backend
- node index.js

# Frontend
- Mene frontend kansioon
- cd frontend

- Käynnistä frontend
- ng serve

Sovellus avautuu osoitteeseen: http://localhost:4200/
